## 2. 命名

| 规则 | 示例 |
|------|------|
| 小写 + 下划线 | `bigwin_start.pag` |
| 文件名带档位 | `bigWin_1024.pag`、`glow_loop_720.pag` |
| 入场 / 循环分开 | `*_start.pag` + `*_idle.pag` |
| 禁止中文、空格 | — |

**分段链**（六段合成尺寸必须一致）：`bigwin_start` → `bigwin_idle` → `supwin_start` → `supwin_idle` → `megawin_start` → `megawin_idle`


## 3. 建议合成尺寸（制作规范，不决定同屏路数）

按**实际可见区域**做画布，勿无脑 1920 全屏；竖屏机台对齐设计分辨率（如 1080×1920），其余透明。  

## 4. 导出要点

- 帧率：循环 **30 fps**，避免 60 fps 全长位图序列  
- 循环段首尾视觉一致，单独导出 `*_idle.pag`  
- **循环时长 ≥ 1 秒**；循环总帧数须为帧率的**整数倍**（如 30 fps → 30、60、90 帧，对应 1s、2s、3s），保证无缝循环   
- 需透 UI 处保留 Alpha，勿铺不透明底  

| **Videos** | BMP 预合成数；循环背景尽量 **1** |
| **Graphics** | 图形内存占用；**尽量 < 10 MB**； |

## 5. 性能与同屏预算（2026-07 真机）

**同屏掉帧本质看 Graphics（图形内存 / 位图缓存），不是合成尺寸。**  
**磁盘体积**是交付最好查的 proxy；**Videos / Graphics** 是 PAG Viewer 里最准的指标。


**新同屏组合须真机验收**；Viewer 中 Image AVG + Present AVG 接近 33 ms 时，视为单路极限，勿再叠加。


避免「Graphics 过大 + 多路同屏」叠加。
