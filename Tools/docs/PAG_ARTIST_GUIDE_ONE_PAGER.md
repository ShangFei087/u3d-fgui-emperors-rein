# PAG 美术制作规范 · 

**版本 2026-07 · 全项目通用**  

## 2. 命名

| 规则 | 示例 |
|------|------|
| 小写 + 下划线 | `bigwin_start.pag` |
| 文件名带档位 | `bigWin_1024.pag`、`glow_loop_720.pag` |
| 入场 / 循环分开 | `*_start.pag` + `*_idle.pag` |
| 禁止中文、空格 | — |

**分段链**（六段合成尺寸必须一致）：`bigwin_start` → `bigwin_idle` → `supwin_start` → `supwin_idle` → `megawin_start` → `megawin_idle`


## 3. 建议合成尺寸三档位

| 档位 | 长边 | 场景 | 标杆文件 |
|------|------|------|----------|
| 标清 | **720** | 转盘、局部特效 | `glow_loop_720.pag` |
| 弹窗 | **1024** |  主弹窗 |  |
| 全屏光效 | **1920** | 过场,BigWin | `fade.pag` ★ |

按**实际可见区域**做画布，勿无脑 1920 全屏；竖屏机台对齐设计分辨率，其余透明。

## 4. 导出要点

- 帧率：循环 **30 fps**，避免 60 fps 全长位图序列  
- 循环段首尾视觉一致，单独导出 `*_idle.pag`  
- **循环时长 ≥ 1 秒**；循环总帧数须为帧率的**整数倍**（如 30 fps → 30、60、90 帧，对应 1s、2s、3s），保证无缝循环  
- 优先矢量 + 少量位图；控制序列帧张数与分辨率  
- 需透 UI 处保留 Alpha，勿铺不透明底  
- 提交前：PAG Viewer 预览 + 记录宽高、时长、体积  

## 5. 体积与同屏预算（2026-07 真机）

| 指标 | 标准 |
|------|------|
| 单文件 | **≤ 2 MB** 为佳；**> 8 MB 须评审** |
| 真机帧率 | 同屏验收 **≥ 25 FPS** |
| 循环光效 | 优先 **720 档** |

**同屏路数上限（按合成档位，同时播放计数）**：

| 档位 | 合成长边 | 同屏上限 | 典型场景 |
|------|----------|----------|----------|
| 全屏光效 | **1920** | **1 路** | 过场、BigWin 全屏、Fade 类 |
| 弹窗 | **1024** | **2 路** | BigWin 弹窗、奖励面板 |
| 标清特效 | **720** | **4 路** | 转盘、局部光效、点缀 |

混档同屏（如 1 路全屏 + 多路弹窗）须策划/程序提前评审；**全屏档始终最多 1 路**。



避免「全屏重位图循环 + 多路大特效」叠加（实测可跌至个位数 FPS）。
